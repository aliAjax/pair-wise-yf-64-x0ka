# 国际会议同声传译和发言队列控制

源提示词摘要：主持人维护代表发言队列、剩余时间、议题和临时插话；翻译团队维护多语种频道、术语和译员交接；字幕人员修正实时文本。队列调整保留版本，发言者切换后旧译文不会误绑定，并提供低延迟大屏模式和多会议厅隔离。

## 技术栈

Qwik City、TypeScript、Qwik UI、Qwik stores、TanStack Query、Modular Forms、Zod、qwik-speak。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62029`

## 可用流程

- 多会议厅独立维护代表、议题和发言队列，切换厅时数据互不影响。
- 发言人从排队、发言中、完成到跳过，支持临时插话、剩余时间调整和基于事件版本的冲突合并。
- 多语种频道维护译员、术语和交接；交接开始即冻结旧译员区间，完成后新字幕只归属新译员。
- 所有队列调整、译员接替和字幕修订都先写入 `prepared` 意图，再通过浏览器锁原子追加到本地事件流。
- 多标签页后提交者会看到同厅冲突；可普通恢复，或按关键优先级强制合并。
- 字幕修订只追加、不覆盖；交接期间或交接后迟到的旧译文会保留为历史版本，但不会成为当前字幕，也不会落到新译员名下。
- 未完成交接和失败意图持久化，超时、崩溃、关页或刷新后可继续提交。
- 旧版 `conference-interpretation-v1` 快照首次打开时自动迁移为 `v2` 事件账本。
- 低延迟模式只停用装饰动态；队列、交接、冲突意图和已确认字幕仍完整落账。
- 数据保存在浏览器 localStorage，刷新、关闭重开和跨标签页 storage 同步后仍可恢复。

## 本地账本

- 键名：`conference-ledger-v2`
- 结构：`events`（追加事件）、`intents`（意图与失败状态）、`conflicts`（冲突合并记录）
- 视图状态由事件 replay 得到，不把瞬时修改当作唯一事实来源。
